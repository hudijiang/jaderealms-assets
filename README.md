# JadeRealms 3D Model Downloads

Download the versioned single-model ZIP archives from [Releases](https://github.com/hudijiang/jaderealms-assets/releases). Each archive matches the corresponding free download in the [JadeRealms model catalog](https://3dmodelhub.io/models/).

Each release includes SHA-256 checksums. For permitted use and attribution, see the [JadeRealms license](https://3dmodelhub.io/license/) and the notices included in each archive.
